## 🧩 Struttura di un Ruolo

Ogni ruolo è il suo manifesto `<id>.md` in radice, più una cartella `<id>/` con ciò che gli compete:

| File | Contenuto |
| :--- | :--- |
| `<id>/immagine.jpg` | Ritratto dell'agente |
| `<id>/modello.glb` | Busto 3D dell'agente per la plancia della Home (~14k triangoli, texture 1024) |
| `<id>/modello.json` | Dettagli del modello: altezza del collo per l'animazione della testa, generatore, data |
| `<id>/personaggio.glb` | Facoltativo: figura intera con scheletro, che cammina nella plancia con le animazioni CC0 di Quaternius |

L'indice `manifests_index.json` elenca le risorse di ogni ruolo nel campo `risorse`: Sigma Studio le scarica insieme al manifesto e le rimuove quando il ruolo viene disinstallato. I busti sono ricostruiti dalle foto con [TRELLIS](https://github.com/microsoft/TRELLIS) (licenza MIT).

## 🚀 Utilizzo con Sigma Studio

1. **Download da Hub Integrato**: Apri la tab **Galleria Manifesti** in Sigma Studio, naviga nella sezione **Hub Professioni (GitHub)** e premi **Installa / Scarica** sul ruolo desiderato.
2. **Utilizzo Istantaneo in Chat**: Una volta scaricato, l'agente appare immediatamente disponibile nel selettore della Chat AI.
3. **Importazione Diretta**: Puoi importare qualunque manifesto fornendo l'URL `Raw GitHub` nella sezione di importazione personalizzata.

---

## 🛠️ Utilizzo Diretto con Ollama

Puoi creare qualsiasi modello direttamente da terminale eseguendo:

```bash
ollama create nome_agente -f ./nome_file.md
```

Ad esempio:
```bash
ollama create tutor_matematica -f ./tutor_matematica.md
```
